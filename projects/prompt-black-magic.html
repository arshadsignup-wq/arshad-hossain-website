Prompt Black Magic

AI Prompt Library

Why I built this

As a marketer who uses AI tools daily, I was copy-pasting the same prompts over and over from scattered notes. So I built a single library with 100+ curated prompts organized by category.

What it does

It covers Google Ads, SEO, social media, email marketing, and general productivity. You can search, filter by category, and copy any prompt with one click. The whole site is static, fast, and SEO-optimized so other marketers can find it too.

Features

  • 100+ curated prompts across multiple marketing categories
  • Google Ads, SEO, social media, and email marketing prompts
  • General productivity prompts for everyday tasks
  • Search and filter by category
  • One-click copy for any prompt
  • Static site with fast load times
  • SEO-optimized so other marketers can discover it

Tech stack

Vanilla JS · Static Site · SEO-optimized
